# 第二阶段：固定搜索与独立复核

## 当前状态

本包是可复现的数值对照实验，尚不是智能体自主研究运行。
LLM 调用次数为 0。不得把参数优化轨迹称为模型反思或模型提出猜想。

## 密度族

rho(r)=A*r^alpha*exp(-a*r)，0<=a*r<R；其余位置为零。
alpha>=0，a>0，R>0；R=无穷表示不截断。
A=a^(alpha+3)/(2*pi*Gamma(alpha+3)*P(alpha+3,R))，P 是正则化下不完全 Gamma 函数。
因此三维积分为 2。a 是尺度，R 与 alpha 改变形状。

t=N_e(r)/2；q(t)=gammaincinv(alpha+3,t*P)/a。
所有比值沿用第一阶段定义：lambda=C_ratio/C_x。

有限 R 时密度在边界存在跳跃，所以这里只是经典/SCE 基准。
其平方根通常不属于 H1；若要联系有限动能电子态，必须作平滑逼近并检查误差。
这不阻止本阶段研究密度泛函数值值，但阻止把原样密度称为物理可实现波函数密度。

## 固定实验设计

alpha=[0,0.25,0.5,0.75,1]；R=[3,5,8,12,20,40,无穷]：35 次网格实验。
然后固定 alpha=0 与 0.5，分别在 3<=R<=30 内进行有界一维数值优化。
总候选计算81次（具体依赖数值库实现，JSON保留每次结果）；再单独复核候选。
一维优化采用较松容差用于发现候选，所得 R 不是高精度最优参数。

## 本次结果

指数密度：lambda约1.699052430。
截断指数候选 alpha=0，R约11.07：搜索估计约1.699090351，非最终独立复核对象。
不截断 alpha=0.5：lambda约1.700965186。
本轮最好候选 alpha=0.5，R约13.69：收紧容差后 lambda约1.700974139。
独立径向积分重算 D、V、I，与分位数积分一致；归一化、尺度和容差检查通过，共7项。
复核只在候选参数处进行，不是该密度族的最优性证明。

## 下一阶段的智能体工作

1. 接入真实模型，让它读取问题、工具说明、文献证据与现有实验数据。
2. 让模型提出可执行且满足约束的密度修改，记录响应、时间、模型版本。
3. 固定求解器与验收器，模型只能改变候选，不得修改评分标准。
4. 执行候选，独立复核，将失败原因和计算结果返回模型。
5. 至少完成多轮真实提议—工具执行—反馈—修改，保存原始轨迹。
6. 加入平滑边界与有限动能可容许性检查；区分研究失败、数值失败、约束失败。

报告必须单独列出固定搜索、人工修改与模型自主提议的来源。
